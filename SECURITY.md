# Security Policy

## Supported Versions

Security fixes are provided for the latest release in the `0.1.x` line. Older releases are not supported.

## Reporting a Vulnerability

Do not report suspected vulnerabilities in a public issue. Use the repository's **Security** tab and select **Report a vulnerability** to submit a private report.

Include a description of the issue, affected versions, reproduction steps, and potential impact. We will acknowledge the report and provide a status update after triage.

Before publishing the repository, enable private vulnerability reporting in its GitHub security settings so this channel is available.
